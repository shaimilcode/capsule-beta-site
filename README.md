# Capsule beta website

Static marketing, privacy and support pages for the Capsule iPhone beta. Content grounded in the 7 November 2026 DATA-FLOW-AUDIT.md source review. The audit itself is not published.

## GitHub Pages
In repository Settings → Pages, select Deploy from a branch, main, /(root), and Save.

Expected URLs after deployment:
- https://shaimilcode.github.io/capsule-beta-site/
- https://shaimilcode.github.io/capsule-beta-site/privacy.html
- https://shaimilcode.github.io/capsule-beta-site/support.html

No build step, scripts, tracking or external assets. GitHub Issues is the public support channel; users are instructed not to post private information.
